# FH6 Hub Windows Release Layout

Generated by `prepare_release.ps1`.

Directory structure:

- `release/windows/<version>/bundle/Time4ttack-FH6-Hub/`: unpacked app bundle
- `release/windows/<version>/bundle/Time4ttack-FH6-Hub-<version>-bundle.zip`: zipped bundle
- `release/windows/<version>/installer/Time4ttack-FH6-Hub-<version>-Setup.exe`: installer (only if Inno Setup is installed)
- `release/windows/<version>/SHA256SUMS.txt`: checksums for all release files
- `release/windows/<version>/RELEASE_NOTES.md`: release notes draft from template

Publish recommendation:

1. Prefer installer for end users.
2. Keep bundle zip as fallback for machines where installer is blocked.
3. Always publish checksums together with binaries.
